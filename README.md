# Amazon-Recommendation-System

### Problem Statement

Creating and designing a personalized recommendation system using Amazon Product review dataset.
Combine sentiment analysis of review texts with user-product interaction patterns to enhance recommendation accuracy

### Models

- Support Vector Model (SVM)
- Neural Collaborative Filtering (NCF)
- Bidirectional Encoder Representation from Transformers (BERT)
